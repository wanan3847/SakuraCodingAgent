# 项目介绍网站设计

本轮直接参考 `/Users/yangyazhou/awesome-design-md/design-md/apple/DESIGN.md`，不混合其他设计系统。用户指定 🌸 樱花色，替换参考的 Action Blue；其余基础采用 Apple 的白色/灰白画布、深色产品章节、SF Pro 字体层级与表面规则。

## 参考与实际落地

| 参考规则 | 页面实现 |
| --- | --- |
| 白色 #ffffff、灰白 #f5f5f7、深色 #272729 | 首屏、功能与模块区、多 Agent 章节 |
| SF Pro Display 600，正文 SF Pro Text 400 | 项目名、章节标题、说明文案；系统字体回退 |
| 单一动作强调色 | 樱花粉 #f2b1d0 按钮，深粉 #9b3c69 链接和选中态 |
| 产品主导，减少装饰 | 首屏展示终端流程；撤掉大花、轨道与花瓣模块标签 |
| 阴影只属于产品展示 | 唯一阴影用于终端产品图；按钮、模块和卡片无阴影 |
| 全宽章节不圆角 | 白、灰白与深色章节自然交替，无渐变背景 |
| pill / 11px / 18px 圆角规则 | 动作按钮、终端与安装区、独立配置展示 |

品牌直接使用 🌸 emoji。首屏左侧是 Sakura 的项目定位与使用入口，右侧是终端流程示意；图示明确标注，不将模拟流程作为真实运行证据。整体内容为项目介绍、能力、协作机制、Pi 生态、五模块设计和安装方式。真实使用文档单独位于 guide.html。

模块与安装 tabs 支持键盘导航；复制按钮的剪贴板内容已核对；桌面及 390px 手机布局通过实际浏览器检查。减少动态效果偏好受到尊重。导出的五个静态文件不包含 Agent 配置、运行数据或 API。

既有本地运行工具仍在 /workbench，独立 TUI、模型、Pi 包管理与运行机制没有修改。本轮只调整网站。
