## 用户操作

```bash
# 计划和交付
node src/cli/dev.ts plan "修复登录刷新问题" --files src/auth.ts
node src/cli/dev.ts run --plan .sakura/plans/<planId>/v1.json
node src/cli/dev.ts diff .sakura/runs/<runId>/diffs/<runId>.json
node src/cli/dev.ts apply .sakura/runs/<runId>/diffs/<runId>.json

# 历史和运行中补充
node src/cli/dev.ts history
node src/cli/dev.ts resume <runId>
node src/cli/dev.ts instruct <runId> <taskId> steer "保持现有 API"
node src/cli/dev.ts instruct <runId> <taskId> plan "补充边界条件"
```

Pi 中有 `/sakura-cancel`、`Ctrl+Shift+X`、`/sakura-history`、`/sakura-resume`、`/sakura-instruct`。业务 CLI 使用 Ctrl+C 取消。`dispatched` 指原生队列已接受，`applied` 指 pending 图修改生效，不能把接受消息说成模型已经满足要求。
